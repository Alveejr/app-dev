# My Favorite Movie: Interstellar

## Overview

Interstellar is about Earth's last chance to find a habitable planet before a lack of resources causes the human race to go extinct.

- Memorable characters

### Favorite Scene

The most iconic scene is the intense docking sequence where Cooper manually matches the rotation of a violently spinning space station to Hans Zimmer's booming score.
